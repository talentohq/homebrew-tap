# talentohq/tap

Homebrew 6 will not load this cask until you trust the tap.

```sh
brew tap talentohq/tap
brew trust talentohq/tap
brew install --cask talento
```

macOS only. Linux users should use the [GitHub release](https://github.com/talentohq/talento-cli/releases/tag/v1.0.0) installer or packages.
